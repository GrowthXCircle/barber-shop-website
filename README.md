# Cut Craft Hub

A cinematic video-editing studio portfolio presenting creative services, project case studies, pricing, studio information, and contact content.

**Live website:** [cutcrafthub.vercel.app](https://cutcrafthub.vercel.app/)  
**Repository:** [GrowthXCircle/barber-shop-website](https://github.com/GrowthXCircle/barber-shop-website)

## Highlights

- Home, services, portfolio, case-study, pricing, about, and contact routes
- Data-driven portfolio pages
- Responsive shared layout
- Motion effects and scroll-progress feedback

## Technology

React 19, TypeScript, TanStack Router, TanStack Start, Vite 7, Tailwind CSS 4, Framer Motion, and Lucide React.

## Local development

Node.js 22 or newer and npm are recommended.

```bash
git clone https://github.com/GrowthXCircle/barber-shop-website.git
cd barber-shop-website
npm install
npm run dev
```

Create and preview a production build:

```bash
npm run build
npm run preview
```

Run the configured linter with `npm run lint`.

## Project scope

This is a frontend demonstration project, not the website of an operating business. Projects, prices, enquiries, testimonials, and business details are illustrative.
